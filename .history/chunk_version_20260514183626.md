# Chunk Backend定位修改

1. 时空数据块预构建与重分配
    训练前根据参数实现时间窗口切分和空间切分两阶段
    空间切分得到各时间窗口下的负载向量，根据负载向量均衡策略执行空间分配
    训练参数修改后少量空间块的迁移

2. 基于时空数据块管理的统一数据层
    使用统一的图数据结构作为训练前的完整图表示，避免冗余存储
    DTDG 从中派生 snapshot 视图，
    CTDG 从中派生 event 视图。
    根据预构建时空数据块构建无冗余通信路由

3. 三类异步通信流水线管理
    通信统一为三类：特征/远程 memory fetch、模型层消息传播、memory/cache 状态同步。三类通信在外层 plan 上统一，但执行位置不同，尤其模型层传播需要保留 autograd 支持。

4. 时空数据块感知多采样策略支持
   在基础采样算法的基础上，派生时空双感知的采样策略
   “自适应参数优化”
